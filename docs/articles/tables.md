# Tables of Units and PK Parameters

## View OSP Units

The function
[`tableOfUnits()`](https://www.open-systems-pharmacology.org/OSPSuite.Addins/reference/tableOfUnits.md)
displays a datatable (see [`{DT}`](https://rstudio.github.io/DT/)
package) of dimensions and units available in OSPSuite. RStudio users
can also access the table using the Addin as illustrated in the video
below.

View OSP Units Video

[Video](https://www.open-systems-pharmacology.org/OSPSuite.Addins/articles/videos/table-units.mp4)

> **🛈 Note**
>
> OSPSuite.Addins also provides a unit converter addin, whose dedicated
> article is available [here
> 🔗](https://www.open-systems-pharmacology.org/OSPSuite.Addins/articles/unit-converter.md)

## View PK Parameters

The function
[`tableOfPKParameters()`](https://www.open-systems-pharmacology.org/OSPSuite.Addins/reference/tableOfPKParameters.md)
displays a datatable (see [`{DT}`](https://rstudio.github.io/DT/)
package) of PK Parameters available in OSPSuite. RStudio users can also
access the table using the Addin as illustrated in the video below.
