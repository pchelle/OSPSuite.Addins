# Insert OSPSuite Template

The function
[`insertOSPSuiteTemplate()`](https://www.open-systems-pharmacology.org/OSPSuite.Addins/reference/insertOSPSuiteTemplate.md)
inserts in the current location of a RStudio (i.e. last position
clicked) a template R code for loading a simulation, defining outputs
and running its simulation results and PK analyses.

Users can then modify the template to fit their needs.
