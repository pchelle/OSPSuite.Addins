# insertOSPSuiteTemplate

Insert template code in current document aiming at providing a starting
point for users to interact with the `{ospsuite}` package. The code will
include the following steps:

- loads a simulation

- update a simulation parameter

- add output paths to a simulation

- run a simulation

- format simulation results

- save simulation results

- run a PK analysis

- format PK analysis results

- save PK analysis results

## Usage

``` r
insertOSPSuiteTemplate()
```
