# getAbsoluteEGFR

Get eGFR in mL/min from BSA adjusted eGFR in mL/min/1.73m²

## Usage

``` r
getAbsoluteEGFR(egfr, bsa)
```

## Arguments

- egfr:

  Numeric values of BSA adjusted eGFR in mL/min/1.73m²

- bsa:

  Numeric values of BSA in base unit (dm²)

## Value

Numeric values of eGFR in mL/min
