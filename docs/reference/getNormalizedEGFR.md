# getNormalizedEGFR

Get eGFR normalized by BSA in mL/min/1.73m² from population base unit
values

## Usage

``` r
getNormalizedEGFR(egfr, bsa)
```

## Arguments

- egfr:

  eGFR values in base unit (l/min)

- bsa:

  BSA values in base unit (dm²)

## Value

Numeric values of normalized eGFR in mL/min/1.73m²
